- `logged-in.jpg`: root shell using the persistent native filesystem.
- `boot-sequence.jpg`: the DOS loader immediately before entering MINIX.
- `volts.png`: straightened view of Mack's battery-voltage utility running

- `process-memory.jpg`: `ps -axl` process and task memory listing.
- `filesystem-status.jpg`: native filesystem usage and system identity.
